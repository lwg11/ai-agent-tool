📡 API 调试台

    
本地版 mini Postman：粘贴 cURL 一键导入，浏览器直接发请求；跨域被拦时一键生成 Node 脚本（自带全部 headers/cookies）到终端跑。支持环境变量、请求历史（本地保存）。

  


  

    
🚀 发送请求

    

      
      
      
    

    
跨域(CORS)提示：浏览器直连跨域接口可能被拦，被拦时下方会自动给出一键生成 Node 脚本方案。


    

      
      
      
    


    

      

      
    


    

      
Cookie 无法通过 JS 设置（浏览器安全限制），需要带 Cookie 的请求请走「Node 脚本」方式。

      

      
      
快捷添加：
        content-type: json
        accept: json
        x-xsrf-token
      

    


    

      
      

        
        Body 未启用
      

    

  


  

    
🌍 环境变量 （URL / Headers / Body 里写 {{token}}，发送时自动替换；切换环境一处生效）

    

      环境：
      uat
      prod
      
    

    

    
内置示例：{{token}}、{{xsrf}}、{{baseUrl}}——把 URL 换成 {{baseUrl}}/api/...，换环境只改一处。同名变量在多环境下有不同值，发送时按当前选中环境替换。
